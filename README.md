## Design Case Studies Overview

### 01. ÉPURA FORMULARY™ (Skincare Identity & Packaging)
* **Sector:** High-Prestige Biomimetic Clinical Skincare (Paris & Stockholm).
* **Deliverables:** Wordmark construction grid, mineral chromatic architecture, transitional serif typography pairing, and vector 3D packaging mockups.
* **Key Assets:**
  - *No. 01 Dropper Serum (30ml)* in frosted amber glass flacon.
  - *No. 02 Biomimetic Barrier Cream (50ml)* in matte alabaster ceramic jar.
  - *No. 03 Lipid Balm (40ml)* in impact-extruded collapsible aluminum tube.
  - *Rigid Outer Boxes* in 380gsm G.F Smith Colorplan with blind debossed seal.
* **Interactive Controls:** Dynamic product tabs switcher and click-to-copy color palette (HEX, RGB, CMYK, Pantone).

### 02. NØRRE ARCHIVE (AW26 Fashion Social Campaign)
* **Sector:** Contemporary Unisex Tailoring & Heavy Gauge Knitwear (Collection 07: *"Forms in Concrete & Wool"*).
* **Deliverables:** Six cohesive Instagram feed posts built in standard **4:5 portrait ratio (1080 × 1350px)**.
* **Key Assets:**
  - *Post 01 (Hero):* Asymmetrical full-length silhouette against raw poured concrete.
  - *Post 02 (Manifesto):* High-impact Swiss typography poster without photographic distraction.
  - *Post 03 (Product Focus):* *The Brancusi Wide Trouser* with transparent upfront pricing (£385).
  - *Post 04 (Macro Craft):* 400x fiber texture study of 680gsm Scottish wool & mottled horn button.
  - *Post 05 (Still Life):* *The Monolith Box Calf Tote* on an unpolished travertine plinth.
  - *Post 06 (Conversion):* Swiss 48h private client early-access pass.
* **Interactive Controls:** Click any post to open the **Modal Strategy Inspector** (art direction brief, typography specs, sample copywriting, and conversion KPIs).

### 03. MORA COFFEE ROASTERS (Specialty Packaging & Labels)
* **Sector:** Single-Origin Micro-Lots (Copenhagen & Oaxaca / SCA 88–92+).
* **Deliverables:** 250g unbleached Swedish kraft stand-up pouches with modular tipped-on cotton labels.
* **Variants:**
  - *01. Ethiopia Yirgacheffe (Washed)* — 2,100 MASL, Bergamot & Jasmine (Sage Mist accent).
  - *02. Costa Rica Tarrazú (72h Anaerobic)* — 1,850 MASL, Wild Raspberry & Cocoa (Terracotta Ember accent).
  - *03. Colombia Huila (Thermal Shock Honey)* — 1,750 MASL, Toffee Brittle & Citrus (Ochre Umber accent).
* **Interactive Controls:** Variant tabs, live label die-cut blueprint, and compostable degassing valve technical breakdown.

### 04. POSTER ARCHIVE // A1 SERIES (Cultural Event Posters)
* **Sector:** Cultural Institutions & Public Commissions (Berlin, Paris, Stockholm).
* **Format:** Standard International DIN A1 (594 × 841 mm).
* **Posters:**
  - *Poster 01 (RESONANS '26):* Electroacoustic Sound Festival at Kraftwerk Berlin with 12-column Swiss grid and fluorescent vermilion spot silkscreen.
  - *Poster 02 (SUPERSTRUCT / 04):* Architecture & Spatial Void Retrospective at Pavillon de l'Arsenal Paris with multi-level blind debossing.
  - *Poster 03 (NORDIC LIGHT):* Scandinavian 35mm Cinema Symposium at Cinemateket Stockholm with 2.39:1 anamorphic frame and matte silver hot foil.
* **Interactive Controls:** Gallery switcher with hanging industrial clamps and comparative grid anatomy breakdown.

### 05. CIRCA BOTANICALS (Commercial Beverage Advertising)
* **Sector:** Premium Non-Alcoholic Aperitifs & Botanical Sparkling Soda.
* **Deliverables:** Three commercial key visuals demonstrating natural studio lighting rigs and real culinary props.
* **Key Visuals:**
  - *Visual 01 (Noon OOH):* *"Bite into noon"* — Hard 5600K noon sunlight, Kochi yuzu halved fruit, and chiseled sandstone plinth.
  - *Visual 02 (Print Editorial):* *"The 6:00 PM pause"* — Low-angle 2800K golden hour sunset, ribbed crystal coupe glass, and clear ice sphere.
  - *Visual 03 (Paid Digital/DTC):* *"Nothing synthetic. Ever."* — Diffused overhead softbox, sliced stone fruit, and clean 3-column nutrition proof table.
* **Interactive Controls:** Lighting rig scenario analysis and full-funnel media distribution targets.

## Interactive Features & App Testing Guide

The portfolio is fully static, lightweight, and interactive. Use the following verification checklist when testing the web application:

### Feature Testing Matrix

| Feature | Where to Test | Expected Behavior |
| :--- | :--- | :--- |
| **Clean URL Routing** | Any page navigation | URLs work cleanly without `.html` extension (e.g. `/epura`, `/norre`, `/coffee`, `/posters`, `/beverage`). |
| **Color Copy Tool** | `/epura`, `/coffee` | Clicking any color swatch copies the HEX code to the clipboard and triggers a bottom notification toast. |
| **Product Switcher** | `/epura` | Clicking *Serum*, *Cream Jar*, *Aluminum Tube*, or *Rigid Box* swaps the 3D SVG elevation and technical specifications. |
| **Modal Strategy Inspector**| `/norre` | Clicking any of the 6 Instagram posts opens a detail modal with art direction, typography, copywriting, and KPIs. Pressing `ESC` or clicking `CLOSE` dismisses the modal. |
| **Coffee Variant Switcher** | `/coffee` | Toggling between *Ethiopia*, *Costa Rica*, and *Colombia* updates the hero pouch, tasting notes, altitude, and accent color. |
| **Poster Gallery Switcher**| `/posters` | Switching between *Music*, *Architecture*, and *Cinema* swaps the A1 poster canvas with realistic paper textures and gallery hanging clips. |
| **Ad Rig Switcher** | `/beverage` | Switching between *Noon OOH*, *Golden Hour*, and *Provenance* swaps lighting diagrams, prop compositions, and media funnel metrics. |
| **Responsive Viewport** | Mobile / Tablet / Desktop | Navigation collapses gracefully, grids adjust (1-col on mobile, 2-col on tablet, 3-col on desktop), and touch targets remain accessible. |

## Local Testing & Development

You can run and test this application locally using any standard HTTP server:

### Option A: Python (Built-in)
```bash
# Clone the repository
git clone https://github.com/v0rade/Graphic-Design.git
cd Graphic-Design

# Start local server on port 3000
python -m http.server 3000
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Option B: Node.js / NPX
```bash
# Run instantly with npx serve
npx serve . -p 3000
```

## Architecture & Tech Stack

* **Structure:** Pure Semantic HTML5 with SVG Vector Graphics.
* **Styling:** Tailwind CSS (Utility-First via allowlisted CDN) with custom CSS variables for typography and lighting shadows.
* **Typography:** System-safe editorial stacks (`Didot / Bodoni MT`, `Neue Haas Grotesk / Plus Jakarta Sans`, and `SF Mono / Space Mono`).
* **Interactivity:** Vanilla JavaScript (zero heavy framework runtime dependencies, ~0ms load time).
* **Hosting & Routing:** [Vercel](https://vercel.com/) with Clean URLs enabled via [`vercel.json`](vercel.json).

## Deployment

This repository is configured for automated CI/CD deployment with Vercel:

1. Connect your GitHub repository to [Vercel](https://vercel.com).
2. Framework Preset: **Other** / Root Directory: `./`.
3. Every `git push` to `main` automatically triggers an instant production deployment.

```bash
# Manual CLI Deployment (Optional)
npx vercel --prod
```
